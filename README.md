# Something Project v0.3

**Something Project** is an experimental operating system project made with a custom kernel written mainly in C, with Assembly used for low-level operations and the boot process.

The project is designed to work with simple and familiar C functions while hiding low-level hardware operations behind its own kernel functions.

For example, the project has its own `kernel.h` header, which provides functions such as:

```c
print("Hello World");
input(command);
```

The project follows a **Unix-like** and **minimalist** philosophy.

---

## 💿 Create the ISO

### 1. Open the Terminal

Open a terminal and enter the project directory:

```bash
cd "Something Project v0.3"
```

### 2. Clean Previous Builds

Before compiling, remove files generated by previous builds:

```bash
make clean
```

### 3. Build the Project

Compile the operating system:

```bash
make
```

### 4. Verify the Generated Files

After compilation finishes, check the project directory:

```bash
ls
```

The build should generate:

```text
bootloader.bin
kernel.bin
boot.img
something-project-v0.3.iso
```

## 💾 Bootloader

Something Project v0.3 uses a custom bootloader written in **NASM Assembly**.

The bootloader uses BIOS disk services to load the kernel into memory.

The disk layout is:

```text
Sector 0
└── Bootloader

Sectors 1-16
└── Kernel
```

The kernel is loaded into memory at:

```text
0x10000
```

After loading the kernel, the bootloader switches to **32-bit protected mode** and transfers execution to the kernel.

---

## 🧩 Disk Address Packet

The bootloader uses a **Disk Address Packet (DAP)** to describe the disk read operation.

The current configuration loads:

```text
16 sectors
```

starting from:

```text
LBA 1
```

into:

```text
0x10000
```
