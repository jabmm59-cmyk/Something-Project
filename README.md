# Something Project v0.2

**Something Project** is an operating system project made with a custom kernel written in C and Assembly.

The project is designed to work with simple and familiar C commands and functions.

For example, the project has its own `kernel.h` header, which provides functions for the kernel in a similar way to how standard C libraries such as `stdio.h` provide functions for C programs.

The project follows a **Unix-like** and **minimalist** aesthetic.

---

## 💿 Create the ISO

### 1. Open the Terminal

Open a terminal and enter the project directory:

```bash
cd "Something Project v0.2"
```

### 2. Clean Previous Builds

Before compiling, remove files generated by previous builds:

```bash
make clean
```

### 3. Build the Project

Compile the operating system:

```bash
make
```

### 4. Verify if the ISO Was Created

After the compilation finishes, check the files in the project directory:

```bash
ls
```

The bootable ISO should be generated inside the `iso/` directory.

You can check it with:

```bash
ls iso
```

If the ISO was not created, check the **Tags** of this repository and look for:

**Something Project ISO 💿**

## 🧠 Kernel

The kernel is the main part of Something Project.

It is written using **C** together with **Assembly** for low-level operations and the boot process.

### Main Kernel Files

| File | Description |
|---|---|
| `kernel.c` | Main kernel source code |
| `kernel.h` | Kernel functions and definitions |
| `boot.s` | Assembly boot code |
| `linker.ld` | Kernel linker configuration |
| `print.c` | Functions for displaying text |
| `keyboard.c` | Keyboard input handling |
| `keyboard.h` | Keyboard definitions |

---

## ⌨️ Keyboard

Something Project includes basic keyboard input support.

The keyboard system is implemented mainly through:

```text
keyboard.c
keyboard.h
```

These files allow the kernel to receive input from the keyboard.

---

## 🖨️ Text Output

The project also contains a basic printing system:

```text
print.c
```

This is responsible for displaying text directly through the kernel.

---

## 🔧 Build System

Something Project uses **Make** to automate the compilation process.

The main build file is:

```text
Makefile
```

The basic commands are:

```bash
make clean
```

and:

```bash
make
```

`make clean` removes generated files, while `make` compiles the project and creates the necessary files for the operating system.
