# Something Project

It is a project of an OS made with A Kernel that works with normal C commands. For example, the file "kernel.h" works like the lib "studio.h" of C

## Create the ISO💿

1. On the Terminal:

```cd \ Something\ Project \ v0.1

   make clean

   make```

2. Verify if the ISO was created:

- ls

If the file "Something Project v0.X" appear, the ISO was created.

If the ISO wasn't created for to the tags of this repository, go to the tag "Something Project ISO💿"

- Aesthetic: unix-like and minimalist.
